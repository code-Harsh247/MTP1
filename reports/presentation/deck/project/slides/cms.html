Output

Replaces one MLP block with k copies that differ only in how often they are updated.

Update rule: each copy changes once per period C, by the sum of the gradients it gathered (NL Eq. 71):

θ ← θ − Σ η ∇L, summed over its last C steps

Independent variant: the output is a learned weighted sum of all copies (Eq. 74).

Pretrained start: every copy begins as the pretrained MLP (Sec. 7.3).

Evidence: less forgetting than EWC on class-incremental text classification.

A. Behrouz, M. Razaviyayn, P. Zhong and V. Mirrokni, “Nested Learning: The Illusion of Deep Learning Architectures,” NeurIPS 2025.

(45 seconds) The Continuum Memory System, CMS, is how Nested Learning turns this idea into a layer. It replaces one MLP block with several copies that differ only in how often they are updated. In my setup there are three: a fast copy updated every step, a medium one every 16 steps, and a slow one every 256 steps. Each copy is updated once per period, by the sum of the gradients it gathered during that period — equation 71 in the paper. In the independent variant, which I use, the layer’s output is a learned weighted sum of the copies. All copies start from the pretrained MLP, so CMS can be dropped into a pretrained backbone. And in the paper, CMS reduced forgetting compared with EWC on class-incremental text classification. So the intended effect is clear: when the fast copy overwrites old people, the slow copy still remembers them.
