Catastrophic Forgetting in Continual Ear Recognition

11

(40 seconds) Nested Learning is a new idea from NeurIPS 2025. It looks at a network as many parts, each learning from the data it sees. The key is that parts can learn at different speeds. A part updated every step changes quickly; a part updated rarely changes slowly. On the right, each row is one part, and a filled dot means it updated: the fast part all the time, the slow part only once. Why could this stop forgetting? The fast part quickly takes in the new people, and quickly loses the old ones. But the slow part changes so little that it can still know the old people.
